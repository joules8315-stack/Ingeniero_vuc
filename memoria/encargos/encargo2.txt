que empieza por raya baja es una funcion, y exige verla declarada. El bloque de ese comando usa cinco

sobre ese bloque muere antes de empezar con FALTA_MATERIAL pidiendo cinco funciones que no existen ni
pueden existir. Pasa igual a Codex y nos tiene parados a todos. Quitando la raya baja de esos cinco
nombres de paso, el bloque hace exactamente lo mismo y deja de disparar el aviso falso.

def main():
    if cmd == "resumen-del-plan":
        if len(sys.argv) < 4:
            print('Uso: python ingeniero.py resumen-del-plan <numero> "<el resumen>"')
            return 1
        try:
            import arnes.puerta_del_plan as pdp
            numero = sys.argv[2]
            resumen = " ".join(sys.argv[3:])
            apuntado = pdp.apuntar_resumen(numero, resumen, AQUI)
            if apuntado:
                print("Apuntado el resumen del plan %s." % numero)
                return 0
            print("No se pudo apuntar el resumen del plan %s." % numero)
            return 1
        except Exception as fallo:
            print("No se pudo apuntar el resumen: %s" % fallo)
            return 1
